1. Công dụng

Vẽ một khối kết cấu (shape) ốp theo bề mặt đường cũ hiện hữu. Mặt trên của khối bám đúng địa hình mặt đường cũ; mặt đáy là mặt đó dịch xuống một khoảng bằng chiều dày H. Hai đầu là vách thẳng đứng.

Dùng để bóc tách / thống kê khối lượng lớp kết cấu đường cũ trong corridor (vd: cào bóc mặt đường hiện trạng trước khi làm mới).

2. Điểm gắn (Attachment)

Sub gắn tại origin / marker point, đặt trên mặt đường cũ tại offset của điểm gắn trong assembly. Khối trải sang trái WL và phải WR quanh điểm gắn.

Trong Assembly: kéo sub thả vào marker mong muốn (thường là tim đường hoặc mép phần xe chạy cũ).

Ghi chú:

  • WL, WR, H hiển thị đơn vị m (kiểu chiều dài). Nhập trị dương; trị âm tự quy về 0.
  • H ≤ 0 sẽ tự lấy lại 0.300 m.
  • Mặt đáy luôn mang code cố định DayDC, vách đứng mang code V-DC (không sửa qua tham số).

Lưu ý quan trọng: Phiên bản hiện tại chưa tiêu thụ TL/TR lúc tính toán — bề rộng luôn lấy theo WL/WR. Hai target này chỉ hiện sẵn trong danh sách. Nếu cần khối chạy bám theo offset target (như bản SAC gốc), xem mục 7.

5. Đầu ra (Codes)

Để hiển thị/đặt khối lượng đúng, các code sau phải có trong Code Set Style đang dùng:

  • Shape code: KCDC (hoặc trị CS bạn nhập) — gán material/hatch cho khối kết cấu.
  • Link codes: MDC (mặt trên, hoặc trị CL), DayDC (mặt đáy), V-DC (vách).

Nếu code chưa khai trong Code Set Style, Civil 3D vẫn dựng hình nhưng không hiển thị nét/màu theo style và không gom được khối lượng theo shape đó.

6. Quy trình dùng nhanh

  1. Nạp sub vào palette: chạy lệnh import của add-in (đổ .pkt/.atc vào tool palette).
  2. Tạo Assembly: CreateAssembly → đặt baseline.
  3. Gắn sub: chọn Kết cấu đường cũ trên palette → click vào marker trên assembly.
  4. Chỉnh tham số: chọn sub → Properties → đặt WL, WR, H, CL, CS.
  5. Tạo Corridor với assembly này + alignment + profile.
  6. Gán target EG = mặt đường cũ (Surface). (TL/TR bỏ trống.)
  7. Rebuild Corridor. Khối kết cấu xuất hiện bám mặt đường cũ.
  8. Code Set Style: đảm bảo có KCDC, MDC, DayDC, V-DC.

7. Tùy biến & giới hạn đã biết

Bước sample mặt (SampleStep = 0.5 m). Mặt trên/đáy là polyline lấy mẫu đều 0.5 m theo offset (xấp xỉ StripSurface của SAC, vốn chèn đỉnh tại mỗi giao tuyến TIN). Muốn bám TIN mịn hơn → giảm SampleStep xuống 0.25 hoặc 0.1 m trong class (đánh đổi: nhiều điểm/link hơn, corridor nặng hơn).

Dùng offset target TL/TR. Cần đọc offset từ target tại từng station và thay cho WL/WR ở chỗ đánh dấu // TODO(offset target) trong code. API offset-target tùy framework; chưa bật mặc định.

Layout mode. Khi xem trên Assembly (chưa có surface), sub vẽ khối chữ nhật phẳng đúng WL/WR/H để preview hình dạng. Hình bám-địa-hình chỉ xuất hiện khi corridor có target EG.

Bắt buộc có EG. Không gán surface → sub thoát, không tạo hình. Đây là chủ đích (tránh dựng khối rác khi thiếu dữ liệu).
